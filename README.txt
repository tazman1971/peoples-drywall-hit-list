People's Drywall Hit List — iPhone version

This is an installable PWA. It stores job data locally on the iPhone/browser.
For Home Screen installation, the app must be opened from a web address (Safari's Add to Home Screen requires a hosted page). No Netlify is required; this package can be hosted on any simple static host.

Features:
- Dashboard
- Drive-Bys
- Follow Ups
- Large Projects
- Dates, tender dates, values and notes
- One-tap Call and Email
- Local storage
- Offline cache after installation
